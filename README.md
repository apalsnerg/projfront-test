# Readme

This repository contains files created during the development of a real-time collaborative code editor web application by Team 1 during the course Projekt webbprogrammering frontend (aka Projfront) at Blekinge Institute of Technology.

The application is powered by Vite+React and uses Monaco Editor as a code editor library.

## Get started
To begin, click the green (<> Code) button and copy the HTTPS or SSH link. Then, open your terminal and run the following command to download the code onto your machine.

```bash
git clone <repo-clone-link>
```

Then, install the required project dependencies with your package manager of choice.

With npm:
```bash
npm install
```

Finally, serve the website locally using the Vite dev script.
```bash
npm run dev
```

Note: You must place a valid API key from https://auth.emilfolino.se in a .env file in the root folder of your local code to be able to run the program.
